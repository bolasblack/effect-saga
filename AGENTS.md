# Effect

Before changing Effect code, read `repos/effect/LLMS.md` and consult the relevant implementation and tests in `repos/effect/packages/effect/`. Use the subtree as a read-only reference and import from the installed `effect` package.

When updating the pinned Effect dev dependency, update the reference to the same release tag with `git subtree pull --prefix=repos/effect https://github.com/Effect-TS/effect.git effect@<version> --squash`.
